# BoringCache Benchmarks

This repo gathers JSON results from the standalone BoringCache benchmark repos.

## Benchmark Repos

- `boringcache/benchmark-hugo`
- `boringcache/benchmark-hugo-go`
- `boringcache/benchmark-immich`
- `boringcache/benchmark-mastodon`
- `boringcache/benchmark-posthog`
- `boringcache/benchmark-storybook`
- `boringcache/benchmark-opentelemetry-java`
- `boringcache/benchmark-spring-ai`
- `boringcache/benchmark-grpc`
- `boringcache/benchmark-zed`
- `boringcache/benchmark-n8n`

## Data Feed

`data/latest/` is regenerated by `.github/workflows/publish-index.yml`.

- `index.json`: latest complete same-commit actions/cache and BoringCache pair
  for each benchmark lane
- `pairs.json`: selected commit-pair evidence
- `windows.json`: rolling summaries over the selected pair window
- `health.json`: per-lane flow health
- `benchmarks/*.json`: per-benchmark detail payloads
- `report.md`: small generated table for quick human review

## Refresh

```bash
mise exec -- ruby scripts/publish-index.rb
```

The scheduled workflow runs every four hours and commits `data/latest/`.
